Esta es una captura real de hoy. El dueño tiene un solo botón en la pantalla de inicio: prendido, el secretario puede usar el celular desde cualquier red; apagado, se corta el túnel y se cierra el acceso. Volver a prenderlo requiere tener el celular en la mano: nadie puede reactivarlo a distancia.
